# Бот расписания — Чапаева 33 / Пушкина 15

Бот берет расписание прямо из Google Таблиц и показывает его в красивом формате (отличается от референса, но идея та же).

### Источники
- Чапаева 33: https://docs.google.com/spreadsheets/d/1eobrgtYnn3IHf3_47-Vc-H0qsl4PzvXR1Sm6bfUP_qk/edit?gid=647718560
- Пушкина 15: https://docs.google.com/spreadsheets/d/1H6UAGHWJf6IwcTtJW35Z_k4hTp2AudgkNeCOMkMCbOQ/edit?gid=2011998642

### Навигация
```
 /start → Выбор корпуса (Чапаева / Пушкина)
        → Выбор курса (1 курс / 2 курс / 3 курс / 4 курс)
        → Выбор группы (МЦ-26с, МЭ-26в, МС-26р и т.д.)
        → Расписание
```

Каждая группа — отдельная кнопка. Курс выбирается отдельно. Расписание кэшируется на 10 минут.

### Формат сообщения (пример)
```
📅 Расписание для АТ-26в
Чапаева 33 • 01 сентября
────────────────────────
1️⃣ Урок о важном
   👤 Носкова Е.М.
   📍 Пушк.15 • ⏰ 09:00-10:00
   — перерыв 10 мин —

2️⃣ Ин.яз.
   👤 Фадеева О.В.
   📍 Пушк.15 • ⏰ 10:15-11:50
...
```

### Установка
```bat
pip install -r requirements.txt
set BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER
python bot.py
```

Токен взять у @BotFather → /newbot

### Файлы
- `bot.py` — логика бота (aiogram 3)
- `parser.py` — парсер Google Sheets (CSV export, без API ключей)
- `config.py` — настройки корпусов
- `requirements.txt`

### Команды
- `/start` — главное меню
- `/schedule` / `/rasp` — быстро к выбору корпуса

### Обновление
Кнопка 🔄 Обновить сбрасывает кэш и перечитывает таблицу.
